# ADR-014（离线码）: data URL 单角色页 — 零网络兜底的极致方案

- 日期: 2026-09-06
- 状态: 已接受

## 背景

场景：玩家连不上说书人 instance（Zerotier 内网部署、弱 Wi-Fi、防火墙）。
问题：有没有"QR 码直接解码出 HTML"的零网络方案？

## 决定

1. **data URL 单角色页**：`data:text/html;base64,PGh0bWw+...`，内容为
   角色名 + 一句话能力 + 图标 + 提示语，控制在 1KB 内（QR 版本 40-L 约 2900 字节，
   base64 膨胀 33% 后仍安全）
2. **与在线分享页（F-23 扫码）的分工**：
   - 离线码：单角色、零网络、给单个玩家（抽码场景）
   - 在线页：多角色列表、要保密脱敏、给全场（列表分享场景）
   列表内容超容量且需动态生成，不能用离线码替代
3. **极致简化选项**：不放 HTML 直接放纯文本 `【僧侣】每个夜晚…`，任何扫码器可读；
   base64+HTML 的优势是可渲染图标和排版，体验更接近"摸到token"
4. **与抽码（F-24）结合**：抽码默认生成离线码（零网络），说书人 instance 在线时
   可选生成在线码（带 HMAC 校验、一次性、显示节奏控制）

## 后果

- 正面：完全零网络依赖；Zerotier/内网部署场景完美兜底；实现极简（无路由无存储）
- 负面：内容超容量时退化为纯文本；无保密性（任何人扫到即看）——但单角色码
  本身就是发给对应玩家的，无保密需求
