# ADR-013（抽码）: 盲抽袋数字化 — QR 码 + 盐 + 一次性 + HMAC 防篡改

- 日期: 2026-09-06
- 状态: 已接受

## 背景

线下盲抽袋实体化：玩家闭眼从袋中摸角色标记。数字化复刻需满足：
1. 玩家肉眼无法提前知道内容（QR 码天然满足）
2. 防玩家解码/篡改/重扫

Pocket Grimoire 实体流程参考：玩家拿到说书人的 iPad，从背朝上的 token 里随机选取一个，
点击后显示自己（认知的）角色，同时填写昵称，看完后返回背朝上页面，
将设备传给下一位；已选 token 置灰不可再点击。
本项目的抽码实现一比一复刻该流程，仅增加“重扫”机制（点击已选 token 可重新展示 QR）。

## 决定

1. **payload 结构**：`{ roleId, nonce, hmac }`，nonce 为 32 字符随机盐，
   HMAC = HMAC(roleId + nonce, key = gameId)。篡改 roleId 后校验失败 → "无效码"
2. **一次性**：扫完记录 nonce 已用，重扫显示"该角色已被领取"。防玩家偷看后再扫
3. **显示节奏**：扫码后不直接亮角色名，显示"角色已分配，请等待说书人确认"——
   说书人端确认后（或约定暗号后）才显示。保留实体局"说书人看袋后统一发牌"的节奏
4. **与实体token共存**：说书人可选"发码"或"实体袋"两种模式，不强制

## 后果

- 正面：零道具成本；随机性密码学可验证；防作弊强于实体袋（实体袋可被摸牌手法作弊）
- 负面：需要每个玩家有手机且能扫码；实体局的"摸袋仪式感"部分流失
