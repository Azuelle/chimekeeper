# ADR-002: v1 魔典视图用环形固定布局，自由摆放推迟到 v1.5

- 日期: 2026-09-05
- 状态: 已接受

## 背景

Pocket Grimoire 的自由摆放 token 是其核心魅力，但自由拖拽 + 触控 + 缩放是
全项目交互复杂度最高的部分，也是 AI 实现质量最不稳定的部分。
若 v1 就做，会显著推迟"可用闭环"的到达时间，增加烂尾风险。

## 决定

v1 魔典视图采用环形固定布局（townsquare 式）：座位按编号围圈，
token 位置自动计算，说书人不可拖动。自由摆放（含提示 token 任意位置）
列入 v1.5。

## 后果

- 正面：v1 提前约 2-3 周可用；环形布局在手机上天然更不易误触
- 负面：习惯 Pocket Grimoire 的说书人会觉得受限；v1.5 时需重做视图层（但数据模型不受影响——座位与 token 的存储模型自始即包含位置无关与位置相关两套字段的扩展空间）
