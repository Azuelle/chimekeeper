# ADR-016（发牌）: 指定发牌模式 — 顺序翻页 QR + 往回防呆

- 日期: 2026-09-06
- 状态: 已接受

## 背景

奇遇角色【园丁】的能力是"由说书人决定每名玩家的具体角色"（中文百科【设置调整】）。
盲抽模式（ADR-013）的随机性来自玩家自选背朝上的 token，没法覆盖园丁——
这时候角色分配权在说书人手里，玩家没有选择权。类似场景还有悟道者局的说书人微调、
无神论者局的自由构成，以及纯手动发牌偏好。

## 决定

指定发牌与盲抽的核心差别：

| 维度 | 盲抽模式（ADR-013） | 指定发牌模式（本 ADR） |
|---|---|---|
| 分配权 | 玩家自助选 | 说书人预先指定 |
| UI 形态 | 背朝上 token 阵列，点了即抽 | 顺序翻页：1 号 → 2 号 → … |
| QR 码 | 玩家点 token 时生成 | 按座位逐个展示（data URL 离线码，ADR-014） |
| 防呆 | 已选 token 置灰 | **往回翻页 = spoiler 高斯模糊 + 确认弹窗** |

具体流程：

1. 说书人排好座位并指定每个座位的角色，点击"开始发牌"。
2. 屏幕显示 1 号座位的 QR 码；玩家扫完后，说书人点"下一个"，依次发到全员。
3. 若说书人手滑点"上一个"回看已发座位，该 QR 码**先不直接显示**，而是覆盖高斯模糊，并提示"这个角色已经分发过了，确定要再次展示吗？"，需要二次确认才移除。防止角色信息泄露给下一家。
4. 复用 ADR-013/014 的 QR payload、data URL 离线码和认知覆盖约定，本 ADR 只定义 UI 流程差异。
5. 抽袋环节提供三种模式："盲抽袋"（默认）、"说书人指定"、"实体袋"。指定模式下需先完成分配，再进入发牌翻页。
6. UI 文案用"说书人指定发牌"，不用内部速记"发牌"。

## 后果

- 正面：园丁/悟道者/无神论者等需要说书人定牌的场景有 UI 支持；往回翻页防呆避免信息泄露；与盲抽模式互不干扰。
- 负面：发牌翻页引入额外的 UI 状态机（顺序浏览 + 确认弹窗），实现成本中等。
