# ADR-016（发牌）: 指定发牌模式 — 顺序翻页 QR + 往回防呆

- 日期: 2026-09-06
- 状态: 已接受

## 背景

奇遇角色【园丁】："由说书人决定每名玩家的具体角色"（中文百科【设置调整】）。
盲抽模式（ADR-013）的随机性来自玩家自助选择 token，不适用于园丁——
角色分配权在说书人手里，玩家没有选择权。类似场景：悟道者局的说书人微调、
无神论者局的自由构成、纯手动发牌偏好。

## 决定（与盲抽模式的区别）

| 维度 | 盲抽模式（ADR-013） | 指定发牌模式（本 ADR） |
|---|---|---|
| 分配权 | 玩家自助选（随机性来自选择） | 说书人预先指定 |
| UI 形态 | 背朝上 token 阵列，点了即抽 | 顺序翻页：1号座位→2号→… |
| QR 码 | 玩家点 token 时生成 | 按座位逐个展示（data URL 离线码，ADR-014） |
| 防呆 | 已选 token 置灰 | **往回翻页 = spoiler 高斯模糊 + 确认弹窗** |

1. **流程**：说书人排好座位 + 指定每个座位的角色 → 点"开始发牌" → 显示
   1 号座位的 QR 码 → 玩家扫完 → 说书人点"下一个" → 2 号 → … → 全员发完
2. **防呆（核心设计）**：点击"上一个"往回翻页时，该座位的 QR 码**不直接显示**——
   先覆盖一层高斯模糊 + 文字提醒"这个角色已经分发过了，确定要再次展示吗？"
   需要二次确认才移除模糊。防说书人手滑回翻导致角色信息泄露给下一家
3. **复用基础设施**：QR 码 payload 结构、data URL 离线码、认知覆盖一致性
   全部复用 ADR-013/014，本 ADR 只定义 UI 流程差异
4. **入口**：抽袋环节的模式选择——"盲抽袋"（默认）/"说书人指定"（园丁等）
   "实体袋"三种；指定模式下分配完成后才进入发牌翻页
5. **术语**：UI 文案用"说书人指定发牌"（对照中文百科"由说书人决定"的表述），
   不用内部速记"发牌"

## 后果

- 正面：园丁/悟道者/无神论者等需要说书人定牌的场景有 UI 支持；
  往回翻页防呆防信息泄露；与盲抽共存不互相干扰
- 负面：发牌翻页是额外的 UI 状态机（顺序浏览 + 确认弹窗），实现成本中等
