# ADR-015（内置剧本）: 官方三版内置 + 官方全角色池模式

- 日期: 2026-09-06
- 状态: 已接受

## 背景

1. Pocket Grimoire 内置官方三版剧本（TB/SN-V/BMR），玩家无需找 JSON 即可开局
2. 用户提出"官方全角色池"模式：从全部 143 个官方角色中自由组合剧本，
   支持全员追忆（All Heretics）等特殊玩法——现有 JSON 导入无法覆盖
   （需手动拼 143 角色 JSON，不现实）

## 决定

1. **内置官方三版**：TB（暗流涌动）、SN-V（黯月初升）、BMR（梦殒春宵）的
   完整角色列表作为内置剧本，从 `src/data/official-roles.json` 注水库提取
   （team 字段分组），无需网络即可加载
2. **官方全角色池模式**：特殊剧本选项"自由组合"，说书人从全部 143 个官方角色中
   勾选任意数量角色组成临时剧本。支持：
   - 按类型筛选（镇民/外来者/爪牙/恶魔/旅行者/传奇/奇遇）
   - 按剧本筛选（只看 TB / 只看 SN-V / 全部）
   - 搜索角色名
   - 实时显示当前选择的阵营构成（X 镇民 / Y 外来者 / Z 爪牙 / W 恶魔）
3. **特殊玩法支持**：全员追忆（All Heretics）、无神论者局（Atheist）、
   军团局（Legion）等打破常规构成规则的玩法，通过"自由组合"模式手动配置
4. **与 JSON 导入共存**：内置剧本和自由组合是快捷入口，JSON 导入（F-01）
   仍是自定义剧本的完整路径

## 后果

- 正面：零配置开局（内置三版）；全员追忆等特殊玩法可行；与注水库数据同源，
  无重复维护
- 负面：自由组合模式无剧本 JSON 导出（v1 可手动截图配置，v2 再补导出）；
  143 角色全量渲染需虚拟滚动优化（v1 可接受卡顿，M1 实测后决定）
