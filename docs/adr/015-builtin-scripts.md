# ADR-015（官方库）: 内置官方三版剧本 + 官方全角色池模式

- 日期: 2026-09-06
- 状态: 已接受

## 背景

1. 对齐 Pocket Grimoire：开箱即用，玩家不用先去官方工具导出 JSON
2. 社群玩法（全员追忆等）需要"所有官方角色都在池子里"的剧本形态，
   手搓 143 角色 JSON 不现实
3. 我们已有 143 官方角色事实库（ADR-007 注水库），构建剧本 JSON 只是筛选问题

## 决定

1. **内置官方三版**：暗流涌动（TB）/ 黯月初升（BMR）/ 梦殒春宵（SNG）
   - 从 `official-roles.json` 按角色集合筛选生成（构建脚本一次性产出，
     打包进 `src/data/builtin-scripts/`）
   - UI 上是"书架"（F-14）里的预置项，零导入直接开桌
2. **官方全角色池模式**：143 角色全部可抽的特殊"剧本"
   - 用途：全员追忆、自由组局实验、特殊奇遇角色局
   - 实现上就是一张 roles 列表全量打开的 Script，与普通剧本同构
   - UI 上在书架（F-14）中作为独立入口，标注"官方全角色池（实验玩法）"
3. **版权边界**：内置的只是角色 id 集合 + 事实字段（夜序号/阵营/setup 标记），
   角色名与能力文案由注水库提供（已按 ADR-004 版权线处理：自写转述/外链），
   不复制官方剧本 PDF 或 Almanac 原文

## 后果

- 正面：开箱即用；社群玩法解锁；零网络（打包进构建产物）
- 负面：官方出实验性角色更新时需要手动同步数据（构建脚本缓解，低频）
