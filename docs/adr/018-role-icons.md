# ADR-018（图标）: 角色剪影运行时外链 + CSS mask 按阵营/队伍着色

- 日期: 2026-09-10
- 状态: 已接受
- 关联: ADR-004（版权线/素材红线）、ADR-005（玩家卡与圆环配色）、F-14（中文显示名，v1.5）

## 背景

M1 起座位 token 内芯只有角色名文本，ADR-005 留了"图标着色待官方素材"的口子。
现引入角色剪影图标（tomozbot/botc-icons，400×400 单色剪影；imp 红 / 士兵蓝），
需要先定：素材怎么用（合规）、颜色怎么算、在哪收口。

关键观察：官方 botc.app 的角色美术**不是运行时着色**——它按队伍预烤 `_g`（蓝）/
`_e`（红）两套位图；真正"按阵营变色"的是 life token（单色纹理 + CSS 渐变叠加）。
官方唯一的运行时 hue 滤镜是色盲模式。因此本项目不复制"预烤两套图"，而是取其技法：
**单色剪影 + 一层 CSS 颜色**。

## 决定

1. **素材只运行时外链**（`src/ui/roleIcons.ts`）：`raw.githubusercontent.com/tomozbot/
   botc-icons/main/SVG/{id}.svg`，不打包进仓库再分发——沿用 ADR-004 §4 / bra1n 路线。
   URL 前缀集中在 `ICON_BASE` 一处，便于换源/钉 commit；`KNOWN_ICONS` 白名单区分
   "精确命中"与"回落通用图标"，避免拼出 404。
2. **着色技法 = CSS mask**：SVG 作 `mask-image`（只用其 alpha 通道），
   `background-color` 决定颜色——所以红色 Imp 剪影可渲成蓝色。收口在
   `ui/tokenSkin.ts` 的 `tokenIconStyle()`，组件只消费。
3. **颜色规则 = 实际阵营优先，回落角色队伍色**（`resolveTint()`）：
   `Seat.alignment`（ADR-005，与队伍解耦）有值即 good 蓝 / evil 红；
   否则按 role.team（善良蓝 / 邪恶红 / 旅行者紫 / 传奇金 / 传说绿）；都无 → 中性灰。
   这使"善良恶魔"的 Imp 图标变蓝，强于官方仅靠外环表达阵营。
4. **座位 token 造型**：剪影居中（略上移平衡重心）+ 角色名沿**底部**弧线
   （SVG `textPath`，全大写，类 clocktower.online/官方 token）；**长名按字符数动态缩字号**
   （`min(15, max(9, 120/长度))`），避免绕成半圆。整卡分组为
   `[角色 token（上）/ 玩家名（下，若有）] | 提示标记区`。圆环边框/柔光由
   `ringSkinFor()` 按阵营着色。**有剪影伴随的角色名不上色**（避免图标与文字抢色）、字重用常规。
5. **全局字体**：正文改用衬线（思源宋 / Noto Serif SC 栈），更贴近官方观感。
6. **降级**：任何角色取不到剪影（DIY/库里没有且无队伍）时组件渲染 `null`，
   回落纯文本，不阻塞渲染。

### 视觉细节（随本 ADR 一并落地，2026-09-11 补记）

以下调整是第 4 条"剪影 + 弧形名"落地的配套视觉细节（部分随本次实现的提交合入），
原为口头讨论、此处补记：

- 座位 token 直径 3.1rem → 4rem；玩家卡 padding 与 token–名牌 gap 相应放宽
  （`app.css`），给剪影和弧形名留出空间。
- 弧形角色名的第 4 条落地值：`fill` = 正文色（`--text`），**常规字重 400**，
  细深色描边（1px，`paint-order: stroke`）保证暗底可读——即"不上色 / 字重常规"。
- 移除 token 金属高光（原 `.token-ring::after` 的 conic-gradient，观感过重，
  非 ADR-005 要求的自绘环本体）。
- 夜单步骤名字重 600 → 500（略降，减少与剪影争视觉；与 token 角色名的常规字重
  不强制相同）。

## 后果

- 正面：一套单色素材覆盖全阵营配色，色盲模式/自定义配色未来只需改 `tokenSkin`；
  与官方 recolor 同源技法，视觉一致；仓库保持零美术资产。
- 负面：依赖第三方无 license 仓库（README 注明版权归各所有者），有改名/删档风险，
  故设 `KNOWN_ICONS` 与文本降级；raw.githubusercontent 为外部依赖，离线/被墙时不显示图标。
- 待办：若日后取得 TPI 授权或本地化需求，仅替换 `ui/` 两模块即可，组件零改动。
