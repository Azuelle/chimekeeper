# ADR-008（抽袋）: 盲抽袋 = 默认构成 + 调整角色高亮 + 手动加减，不做自动调整

- 日期: 2026-09-06
- 状态: 已接受

## 背景

原 `setup.ts: adjustedComposition` 自动计算 Baron 的构成调整。调研中文钟楼百科
【设置调整】页（docs/reference/setup-adjustments.md）后确认完整自动化不可行：

1. 设置调整有 6 级优先级链 + 连锁重检规则（移除带调整的角色需重新按序检查）
2. 涉及说书人自由裁量（教父 ±1、限任意加减、卡扎力外来者数量"通常不超过+1"）
3. Pocket Grimoire 已验证"默认构成 + 高亮提示"方案在实战中够用

## 决定

1. 抽袋主流程：**显示人数表默认构成 → 高亮在场 setup 角色及其调整方向（一句话文案）
   → 说书人手动 +/- 各类型数量 → 袋内总数 ≠ 玩家数时醒目警告但不阻止**
2. `adjustedComposition` 降级为"参考提示数据"（生成高亮文案用），不再是主流程
3. setup 角色的调整方向文案蒸馏自【设置调整】页，做成静态数据表（含官方三版 +
   实验性/华灯初上常用角色），未知 setup 角色（DIY）显示通用提示"该角色会调整设置"
4. 特例处理：隐士显示"-0~1 外来者 +对应镇民（说书人决定）"

## 后果

- 正面：实现简单且覆盖所有剧本（包括 DIY）；把裁决权留给说书人，守 Won't 红线；
  与 Pocket Grimoire 用户习惯一致
- 负面：新手说书人需要自己理解调整规则（缓解：高亮文案 + 详情页跳转百科）；
  `setup.test.ts` 中 Baron 自动计算测试需改为文案提示测试
