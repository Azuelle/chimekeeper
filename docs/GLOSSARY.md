# GLOSSARY — 编号 × 速记名对照表

> 速记名 ≤4 字，说书人黑话风格。聊天 / commit / issue 里「名字+编号」并写
> （如 `F-03 抽袋`、`M2 入夜`）。本表是唯一权威映射，新增功能/决策时同步。

## 里程碑（M）

| 编号 | 速记名 | 一句话 |
|---|---|---|
| M0 | 骨架 | 仓库、CI、文档体系、类型、fixtures，能跑能部署 |
| M1 | 开桌 | 导入剧本 + 排座位圈，手机上能开一局 |
| M2 | 入夜 | 抽袋分角 + 夜单 + 杀后台不丢进度 |
| M3 | 天亮 | 计票/处决 + 流水 + 一键战报 |
| M4 | 补全 | 旅行者/备忘/声称/计时器，线下完整体验 |
| M5 | 上线 | 部署 + 报备 + 对外发布 |

## 架构决策（ADR）

| 编号 | 速记名 | 一句话 |
|---|---|---|
| ADR-001 | 选型 | Vite+React+TS+Zustand+Dexie+Zod，全链路 AI 友好 |
| ADR-002 | 砍范围 | v1 不做自由摆放（固定布局） |
| ADR-003 | 宽容 | 剧本 JSON 宽松解析：未知字段透传，缺字段才报错 |
| ADR-004 | 版权线 | 代码 MIT；不抄 GPL 代码；图标只外链；TPI 政策合规 |
| ADR-005 | 网格 | 魔典用响应式网格，手机两列（官方小程序形态） |
| ADR-006 | 锚点 | 夜单 = 黄昏/爪牙信息/恶魔信息/黎明 系统锚点 + 角色步骤 |
| ADR-007 | 注水库 | 内置 181 官方角色事实库（官方 botc-release 源），纯 ID 剧本自动注水 |
| ADR-008 | 抽袋 | 默认构成+调整角色高亮+手动加减，不自动调整 |
| ADR-009 | v0.5 | 版本分层：先出自用内测版再补旅行者 |
| ADR-010 | 备忘 | 夜晚信息 v1 自由文本填空，结构化推迟 v2 |
| ADR-011 | 锚号 | 座位号=椅子锚点不可变；换位/涟漪=原子交换住户；移除默认退役、复用需显式入池 |
| ADR-012 | 扫码 | 角色分享=同源静态页+PWA缓存，不做实时同步 |
| ADR-013 | 抽码 | 盲抽袋 QR：盐+一次性+HMAC 防篡改，保留说书人确认节奏 |
| ADR-014 | 离线码 | data URL 单角色页，零网络兜底（Zerotier/弱网场景） |
| ADR-015 | 官方库 | 内置官方三版+全角色池模式（开箱即用+社群玩法） |
| ADR-016 | 发牌 | 指定发牌：顺序翻页 QR+往回 spoiler 防呆（园丁等） |
| ADR-017 | 持久化 | 单一当前局+写通双写+独立事件 store；首夜→day/round1；夜单进度持久化 |
