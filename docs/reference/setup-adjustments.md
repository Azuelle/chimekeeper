# 参考：设置调整（盲抽袋构建的规则依据）

> 来源：中文钟楼百科[「设置调整」](https://clocktower-wiki.gstonegames.com/index.php?title=设置调整)
> （最后编辑 2026-08-28，活跃维护）。
> 结论先行：完整自动执行设置调整 = 规则裁决（PRD Won't 红线），
> 本项目采用"默认构成 + 调整角色高亮 + 说书人手动加减"（ADR-008）。

## 正常构成三原则（工具默认遵守）

1. 角色类型/阵营分布按人数固定（官方人数表）
2. 同类型角色出场机会均等，非每局固定
3. 场上不存在多个完全相同角色

## 设置调整能力优先级链（完整自动化的复杂度证明）

1. **炼金术士/科学怪人**：先决定获得的能力，该能力若带设置调整则继续生效
2. **特殊设置方式**：军团、无神论者、戏子等
3. **认知覆盖类**：酒鬼、疯子、提线木偶等（此步后，酒鬼以为的镇民不再产生调整效果）
4. **基础配置变动**：男爵、教父、方古、亡骨魔、气球驾驶员、**隐士**（唯一镇民侧：
   -0~1 外来者 +对应镇民）、召唤师、限、小怪宝、卡扎力、堤丰之首、哨兵（传奇）、
   赶尸人、穷奇、饕餮
   - **先加总全部变化 → 再校验外来者数量区间 → 最后统一调整**
5. **增加特定角色**：唱诗男孩（+1 国王）、村夫（+0~2 村夫）、巡山人（+1 落难少女，
   若少女同时被抽到则不变）
6. 抽取 → 回收 → 首夜的后续操作（堤丰之首/卡扎力转化、赏金猎人转邪）

⚠ 连锁规则：调整过程中移除了带调整效果的角色，其效果一并移除（隐士自移除除外），
需按序重检。

## 对工具的落地含义（ADR-008）

- **显示默认构成**（人数表）
- **高亮所有 setup 角色**并附"调整方向"一句话（如 男爵「+2 外来者 -2 镇民」、
  隐士「-0~1 外来者 +镇民」）——调整方向文案可从【设置调整】页蒸馏成数据表
- **手动加减**：说书人点 +/- 调整各类型数量，实时显示当前袋内构成
- 抽袋数量 ≠ 玩家数时**醒目警告**（红字），不阻止（无神论者/军团等本身可破规则）
