# 参考：认知覆盖（魔典状态层规则）

> 来源：中文钟楼百科[「认知覆盖」](https://clocktower-wiki.gstonegames.com/index.php?title=认知覆盖)
> （最后编辑 2026-06-21）。

## 核心机制

- 玩家抽到的就是认知后的角色 token（酒鬼抽士兵），**说书人事后在魔典挂提示标记**
  （如"是酒鬼"），认知覆盖是魔典层状态，不是抽袋层规则
- 认知覆盖**死亡/醉酒/中毒后仍生效**（否则玩家可通过确认真实角色识破）；只有
  认知覆盖角色离场才失效
- 初始认知覆盖同时覆盖**角色和阵营**（疯子/提线木偶必须以为自己是善良方，
  否则玩家可通过"随时确认阵营"规则立刻识破）；中途创造的认知覆盖不再覆盖阵营
- **差异通知原则**：角色/阵营变化时，对比认知前后，只通知有差异的部分
  （例：初始疯子被方古攻击变邪恶方古 → 不通知；提线木偶被麻脸变占卜师 →
  通知"变为邪恶"，因为认知的善良占卜师 vs 实际的邪恶占卜师有阵营差异）
- **嵌套禁止**：认知覆盖角色不能作为另一认知覆盖的结果（提线木偶→酒鬼→占卜师
  不合规，因为"以为自己是酒鬼"无法获得酒鬼的认知覆盖能力）
- 魔术师是唯一影响**他人认知**的认知覆盖（与互动干扰的区别：只影响信息获取，
  不影响非信息互动）

## 对工具的落地含义

1. **抽袋/抽码（F-03/F-24）**：认知覆盖角色的 token 就是认知后的角色
   （酒鬼=士兵），与实体一致——抽码生成"士兵"码，说书人确认后挂"是酒鬼"标记
2. **魔典（Seat.reminderTokens）**：`{ label: '是酒鬼', sourceRoleId: 'drunk' }` 类标记，
   渲染时覆盖在角色 token 上（粿条复盘里的"酒鬼[无神论者]"方括号语法对应）
3. **夜单（F-04）+ 战报（F-08）**：酒鬼以为自己占卜师 → 说书人给的假信息
   按占卜师格式记录（"X 和 Y 中有恶魔：是/否"），但标注[认知覆盖]来源，
   复盘时玩家能看到"他当时以为自己是占卜师，实际被告知…"
4. **角色变更（F-06 role_change）**：差异通知原则提示战报可记录"通知了玩家什么"
   （如"通知变为邪恶"），作为叙事完整性的一环
