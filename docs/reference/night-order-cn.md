# 参考：夜晚行动顺序（中文社区版）

> 来源：中文钟楼百科[「夜晚行动顺序一览」](https://clocktower-wiki.gstonegames.com/index.php?title=夜晚行动顺序一览)，

> ⚠ 该页明确说明：部分角色顺序相对官方原序有优化调整（附理由），说书人可自选遵循哪套。
> 本文件只记录结论与我们的采用策略，完整顺序表请访问原页面（内容持续更新，不做离线副本以免过期）。

## 关键事实

1. **存在两套夜晚顺序**：bra1n JSON 中的 `firstNight/otherNight` 数值（≈官方原序）
   与中文百科调整序。差异角色多集中在：失忆者（提前至最前）、麻脸巫婆（提前以使新爪牙当晚可行动）、
   各类"死亡触发"能力的排列（死亡造成者先于死亡触发者）等。
2. 中文百科版本覆盖**全部官方角色 + 华灯初上 + 实验性/奇遇角色**，而 bra1n 数据不含后两者。
3. 夜晚顺序表的**系统锚点**：黄昏 → （首夜：爪牙信息 → 恶魔信息）→ 角色行动 →
   （其他夜晚：死亡触发能力群 → 信息类能力群）→ 黎明。
4. 中文百科顺序表中的**结构性提示条目**（非角色）：黄昏、爪牙信息、恶魔信息、
   "信息类角色行动开始"、黎明——这些是夜晚面板的骨架。

## 我们的采用策略（对应 F-04）

- **数据源优先级**：剧本 JSON 自带的 firstNight/otherNight 为基础排序
- **系统锚点内置**：黄昏/爪牙信息/恶魔信息/黎明作为面板固定步骤，不依赖剧本数据
- **角色改写规则**（罂粟种植者/魔术师等）：v1 以提示文案形式展示（"如果 X 在场，跳过 Y"），
  不做自动改写——自动改写属于规则裁决，接近 Won't 清单红线
- **中文百科调整序**：作为 v2 的候选数据包（"推荐夜晚顺序"开关），届时需确认社区授权；
  顺序数值本身是事实数据，但成体系的整理成果应先与钟楼百科维护者沟通
- **fixtures 扩充**：收集含华灯初上角色的国内剧本 JSON，验证 bra1n 数值与中文百科顺序的兼容性
